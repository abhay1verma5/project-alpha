## 1. SSC CGL - Combined Graduate Level

### 1.1 Exam Pattern Evolution (2000-2026)

| Period | Structure | Key Changes |
|--------|-----------|-------------|
| **2000-2010** | Prelims (Paper I: GI + English, Paper II: Quant + English) + Mains (Descriptive) + Interview | 200 marks Prelims, 400 marks Mains; Interview of 100 marks |
| **2011** | Tier I (Objective, 200 marks) + Tier II (Objective, 400 marks) + Tier III (Descriptive) + Tier IV (Skill) | Interview abolished; Tier system introduced |
| **2012-2015** | Tier I (200 Qs, 200 marks, 2 hrs) + Tier II (Paper I: Quant 200 marks, Paper II: English 200 marks) + Tier III (Descriptive) | Negative marking 0.25 per wrong answer in Tier I, 0.50 in Tier II |
| **2016** | Tier I reduced to 100 Qs, 200 marks, 75 min + Tier II unchanged | Duration cut from 2 hrs to 75 min; question count halved |
| **2017-2019** | Tier I: 100 Qs, 200 marks, 60 min + Tier II: Paper I (Quant) 200 marks, Paper II (English) 200 marks, 2 hrs each | Duration further reduced to 60 min for Tier I |
| **2020-2021** | Same pattern, CBT mode confirmed for all | COVID delays; exams went fully online |
| **2022** | Tier I: 100 Qs, 200 marks, 60 min + Tier II merged into single paper (Paper I: 390 marks — Maths 90 + Reasoning 60 + English 90 + GK 75 + Computer 75) | Major overhaul: Tier II merged into one session; Tier III descriptive abolished for most posts |
| **2023-2024** | Tier I: 100 Qs, 200 marks, 60 min + Tier II: Single Session (Section I: 390 marks for all, Section II: varies by post, Section III: varies) | Section-based Tier II continued; Paper-specific modules added |
| **2025-2026** | Tier I: 100 Qs, 200 marks, 60 min + Tier II: Modular (common + post-specific modules) | Normalization across shifts; Tier II further refined with post-specific sections |

## 3. IBPS PO - Probationary Officer

### 3.1 Exam Pattern Evolution

| Period | Structure | Key Changes |
|--------|-----------|-------------|
| **Pre-2011** | Each bank conducted its own PO exam (SBI, PNB, BOB, etc. separately) | No unified banking exam existed |
| **2011** | IBPS established; CWE (Common Written Exam) introduced: Single Objective exam (200 Qs, 200 marks) + Interview | Revolutionary change: unified exam for 19+ public sector banks |
| **2012-2014** | Prelims not yet introduced; CWE: 200 Qs (Reasoning 50, English 40, Quant 50, GK 40, Computer 20) + Interview | Sectional cut-offs introduced |
| **2015** | Two-stage exam introduced: Prelims (100 Qs, 100 marks, 1 hr) + Mains (200 Qs, 200 marks, 3 hrs) + Interview | Major change: Prelims became qualifier only |
| **2016-2017** | Prelims: 100 Qs, 100 marks, 1 hr + Mains: 200 Qs, 200 marks, 3 hrs (added Descriptive English) + Interview | Letter/Essay writing added (25 marks) |
| **2018-2019** | Prelims: 100 Qs, 100 marks, 1 hr (20 min/section) + Mains: 200 Qs, 200 marks, 3 hrs + Descriptive (25 marks, 30 min) + Interview | Sectional timing introduced in Prelims |
| **2020-2022** | Same pattern maintained; COVID delays | Online proctored; normalization across shifts |
| **2023-2024** | Prelims: 100 Qs, 100 marks, 1 hr + Mains: 155 Qs, 200 marks, 3 hrs + Descriptive (25 marks) + Interview (100 marks) | Mains question count adjusted |
| **2025-2026** | Prelims: 100 Qs, 100 marks, 1 hr + Mains: ~155 Qs, 200 marks + Descriptive + Interview | Continued stable pattern |

## 7. Important Formulas & Shortcuts

### 7.1 Quantitative Aptitude - Essential Formulas

#### Speed Mathematics
```
Percentage Shortcuts:
- x% of y = y% of x
- Successive discounts: Net = a + b - (ab/100)
- If price increases by x%, to restore: reduce by (100x)/(100+x)%
- If price decreases by x%, to restore: increase by (100x)/(100-x)%

Profit & Loss:
- If CP = 100, SP = 100 + Profit% = 100 - Loss%
- Dishonest dealer: Profit% = [(True weight - False weight) / False weight] x 100
- Two articles at same SP, one at x% profit, other at x% loss: Always Net Loss = x^2/100 %

Simple & Compound Interest:
- SI = PRT/100
- CI - SI for 2 years = P(R/100)^2
- CI - SI for 3 years = P(R/100)^2 * (3 + R/100)
- Doubling time (Rule of 72): T = 72/R years (approx)
- Tripling time: T = 115/R years (approx)

Ratio & Proportion:
- If a:b = p:q and b:c = r:s, then a:b:c = pr:qr:qs
- Componendo-Dividendo: If a/b = c/d, then (a+b)/(a-b) = (c+d)/(c-d)

Time & Work:
- If A does in 'a' days, B in 'b' days: Together = ab/(a+b) days
- If A is x times efficient as B: Time ratio = 1:x (inverse)
- Pipe & Cistern: Same as Time & Work but with +/- for inlet/outlet

Time, Speed & Distance:
- Relative speed (same direction) = |v1 - v2|
- Relative speed (opposite direction) = v1 + v2
- Train crossing: Time = (L1 + L2) / Relative speed
- Boats: Downstream = (u+v), Upstream = (u-v)
- Average speed for equal distances: 2v1*v2/(v1+v2)
```

#### Geometry Quick Results
```
Triangle Properties:
- Area = (1/2) * base * height = sqrt[s(s-a)(s-b)(s-c)] (Heron's)
- Equilateral: Area = (sqrt3/4) * a^2, Height = (sqrt3/2) * a
- Inradius = Area/semi-perimeter
- Circumradius = abc/(4 * Area)
- In right triangle: Inradius = (a + b - c)/2 where c is hypotenuse

Circle Properties:
- Area of sector = (theta/360) * pi * r^2
- Length of arc = (theta/360) * 2 * pi * r
- If two chords intersect: PA * PB = PC * PD
- Tangent from external point: PT^2 = PA * PB

Mensuration 3D:
- Sphere: V = (4/3)pi*r^3, SA = 4*pi*r^2
- Cone: V = (1/3)*pi*r^2*h, Slant height = sqrt(r^2 + h^2)
- Frustum V = (pi*h/3)(R^2 + r^2 + Rr)
- Cylinder: V = pi*r^2*h, CSA = 2*pi*r*h
```

#### Trigonometry Quick Identities
```
Basic:
- sin^2(A) + cos^2(A) = 1
- sec^2(A) - tan^2(A) = 1
- cosec^2(A) - cot^2(A) = 1

Power Identities:
- sin^4(A) + cos^4(A) = 1 - 2sin^2(A)cos^2(A)
- sin^6(A) + cos^6(A) = 1 - 3sin^2(A)cos^2(A)

If sin(A) + cos(A) = k, then:
- sin(A)cos(A) = (k^2 - 1)/2
- sin^3(A) + cos^3(A) = k(3 - k^2)/2

SSC Favorite: If sin(A) + cosec(A) = k, then sin^n(A) + cosec^n(A) can be derived recursively.
```

#### Algebra Shortcuts
```
- (a+b)^2 = a^2 + b^2 + 2ab
- (a-b)^2 = a^2 + b^2 - 2ab
- a^3 + b^3 = (a+b)(a^2 - ab + b^2)
- a^3 - b^3 = (a-b)(a^2 + ab + b^2)
- If a + 1/a = k, then:
  - a^2 + 1/a^2 = k^2 - 2
  - a^3 + 1/a^3 = k^3 - 3k
  - a^4 + 1/a^4 = (k^2 - 2)^2 - 2
```

### 7.2 Data Interpretation Shortcuts (Banking Exams)

```
Percentage Calculation Tricks:
- 12.5% = 1/8
- 16.67% = 1/6
- 14.28% = 1/7
- 11.11% = 1/9
- 33.33% = 1/3
- 37.5% = 3/8
- 62.5% = 5/8
- 87.5% = 7/8

DI Approximation:
- Always round to nearest whole number first
- Check answer options: if spread is wide (>5%), aggressive approximation works
- For compound growth: use (1+r)^n approximation tables
- CAGR shortcut: For 2 years, CAGR ~ (Growth1 + Growth2)/2 - (Growth1*Growth2)/200

Average Based:
- Weighted average = (n1*a1 + n2*a2)/(n1+n2)
- If 2 groups merge: new avg shifts toward the larger group
```

### 7.3 Reasoning Shortcuts

```
Syllogism (Venn Diagram Method):
- All A are B: A is completely inside B
- Some A are B: A and B overlap
- No A is B: A and B are separate
- Some A are not B: At least one part of A is outside B
- Use complementary pair rule for "either...or" conclusions

Blood Relations:
- Make family tree immediately
- Use symbols: +/- for male/female, = for married, | for parent-child
- Coded relations: first decode all symbols, then draw tree

Puzzles (Banking):
- Start with definite clues (exact positions)
- Eliminate impossible positions
- For circular: fix one person and work relative to them
- For floor-based: start from strongest clue (exact floor number)

Direction Problems:
- Draw on paper, start from origin
- Use Pythagorean theorem for shortest distance
- Remember: clockwise = N -> E -> S -> W

Number Series Patterns:
- Difference series (1st, 2nd, 3rd order differences)
- Multiplication series (x2, x3, x4...)
- Mixed series (alternating operations)
- Square/Cube based series (n^2 +/- k)
- Prime number based series
- Wrong number in series: check all patterns systematically
```

### 7.4 English Language Key Rules

```
Subject-Verb Agreement:
- "Either...or" / "Neither...nor": verb agrees with the nearest subject
- "Along with", "together with", "as well as": verb agrees with the first subject
- Collective nouns: singular verb when acting as unit, plural when individuals
- "Each", "Every", "Everyone": always singular

Common Error Types (SSC + Banking):
1. Subject-verb agreement errors (most frequent: 20%+ of error questions)
2. Tense errors (15%)
3. Preposition errors (15%)
4. Article errors (10%)
5. Pronoun reference errors (10%)
6. Parallelism errors (10%)
7. Modifier errors (10%)
8. Comparison errors (10%)

Idioms Most Tested in SSC:
- Beat around the bush, Burn the midnight oil
- A bolt from the blue, A bone of contention
- At the drop of a hat, Cry over spilt milk
- Hit the nail on the head, Let the cat out of the bag
- Once in a blue moon, Turn over a new leaf
- Burn one's bridges, Cost an arm and a leg

Reading Comprehension Strategy:
1. Read questions first (especially tone/title questions)
2. Skim passage for structure
3. Locate answers using keywords
4. Eliminate obviously wrong options
5. For inference questions: answer must be supported by passage text
```
