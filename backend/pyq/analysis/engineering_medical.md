> analyses (Allen, FIITJEE, Resonance, Aakash, etc.), NTA published data, and historical
> question paper pattern studies. Weightage percentages are approximate averages across
> multiple years and may vary +/-3% in any given year.
>
> Web search tools were unavailable during generation. All data is sourced from training
> knowledge (cutoff: May 2025). Figures for 2025-2026 are projected based on NTA trends.

### 1.1 Exam Evolution Timeline

| Period | Name | Conducting Body | Format |
|--------|------|-----------------|--------|
| 1998-2001 | AIEEE (predecessor concepts) | CBSE | Pen-and-paper |
| 2002-2012 | AIEEE | CBSE | Pen-and-paper, MCQ only |
| 2013-2018 | JEE Main | CBSE | Pen-and-paper + online |
| 2019-present | JEE Main | NTA | Fully computer-based (CBT) |

- From 2020 onward: conducted multiple times per year (Jan + Apr sessions; sometimes 4 sessions).
- From 2023: 75 questions, attempt 75 (no optional). Section A (20 MCQ) + Section B (10 numerical, attempt 5).

### 4.2 Difficulty Comparison

| Aspect | JEE Main | JEE Advanced | NEET |
|--------|----------|--------------|------|
| Overall Difficulty | Moderate | Very High | Moderate |
| Conceptual Depth | Medium | Very Deep | Medium |
| Calculation Intensity | Medium-High | Very High | Low-Medium |
| Tricky/Trap Questions | Few | Many | Some (statement-based) |
| Time Pressure | High (20 min/subject) | Very High | Moderate (3 hrs for 180 Qs) |
| Negative Marking Impact | Moderate | High (varies by type) | Moderate |
| NCERT Sufficiency | 60-70% | 30-40% | 85-95% |

### 4.3 Key Differences in Question Style

**JEE Main:**
- Straightforward application of formulas
- Single-step or two-step calculations dominate
- Numerical value questions test calculation accuracy
- NCERT + one reference book usually sufficient

**JEE Advanced:**
- Multi-concept questions linking 2-3 topics
- Questions designed to test deep understanding
- Multi-correct options require thorough analysis
- Paragraph-based questions test comprehension + application
- Integer-type questions may require 5-6 step calculations
- Often tests edge cases and boundary conditions

**NEET:**
- Heavy emphasis on NCERT textbook content
- Biology is largely factual/memory-based but trending toward application
- Physics questions are NCERT-level with some numerical problems
- Chemistry balances between NCERT facts and basic problem-solving
- Statement-based questions require careful reading

## 7. Recommendations for PYQ Database Enrichment

### 7.1 High-Priority Scrapers to Build/Enhance

Based on the analysis, the following sources would provide the highest-quality structured data:

1. **Mathongo** -- Has JEE Main/Advanced PYQs organized by chapter, year, and difficulty.
   Well-structured HTML that would be easy to parse. Covers 2002-2025.

2. **Allen Digital / Allen Kota** -- Provides free PYQ solutions. Their topic-wise organization
   matches our database schema well.

3. **Shaalaa.com** -- Extremely well-structured question bank with metadata (topic, subtopic,
   marks, difficulty). Covers multiple boards and competitive exams.

4. **NTA Official PDFs** -- For JEE Main (2019-2025) and NEET (2019-2025), official question
   papers with answer keys are released. These are the gold standard for accuracy.

### 7.2 Data Quality Improvements

Based on this analysis, the current `generate_pyq.py` could be enhanced with:

1. **Chapter-level tagging**: The current model has a `chapter` field (blank by default). The
   Gemini prompt should be updated to include specific chapter names from the weightage tables
   above, ensuring generated questions map to real exam distributions.

2. **Difficulty calibration**: The weightage data shows that JEE Advanced questions are
   significantly harder than JEE Main. The Gemini prompt should reflect this distinction.

3. **Question type variety**: For JEE Advanced, the prompt should generate multi-correct MCQs,
   paragraph-based questions, and matrix-match types -- not just single-correct MCQs.

4. **NCERT alignment for NEET**: NEET questions should closely mirror NCERT textbook language
   and examples. The prompt should explicitly reference NCERT chapters.

5. **Year-appropriate patterns**: Questions for 2019+ JEE Main should include numerical-value
   types. Questions for pre-2013 should not.

### 7.3 Coverage Gaps to Fill

Based on the generation plan in `generate_pyq.py`:

| Exam | Current Year Range | Recommended Range | Gap |
|------|-------------------|-------------------|-----|
| JEE Main | 2002-2026 | 2002-2026 | None (good) |
| JEE Advanced | 1998-2026 | 1998-2026 | None (good) |
| NEET | 2005-2026 | 1998-2026 | Missing 1998-2004 (AIPMT era) |

For NEET/AIPMT, questions from 1998-2004 are valuable because:
- Many questions are repeated or adapted from this era
- The difficulty level provides a useful baseline
- Chapter coverage was different (more Class 11 heavy)

### 7.4 Subject-Specific Recommendations

**For JEE Main Mathematics:**
- Increase coverage of Statistics & Probability (weightage has increased post-2019)
- Add more 3D Geometry questions (trending upward)
- Include more Matrices questions with system-of-equations applications

**For JEE Advanced Physics:**
- Ensure multi-concept questions (e.g., mechanics + thermodynamics combined)
- Include more electromagnetic induction with RC/LR transients
- Add fluid mechanics problems with viscosity and surface tension

**For NEET Biology:**
- Genetics questions should focus on Mendelian crosses and pedigree analysis
- Ecology questions should include recent NCERT-style assertion-reason format
- Human Physiology should be the single largest category by question count

**For NEET Chemistry:**
- p-Block questions should emphasize Group 15, 16, 17 reactions and properties
- Organic chemistry should test named reactions through product identification
- Biomolecules chapter is increasingly important (4-5 questions in recent years)
